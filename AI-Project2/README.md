# AI Project 2 – Iris Flower Classification

## Overview

This project classifies Iris flower species using the K-Nearest Neighbors (KNN) machine learning algorithm from Scikit-learn.

The model is trained on the famous Iris dataset and evaluated using accuracy, F1-score, classification report, and confusion matrix.

## Features

- Load Iris dataset
- Data preprocessing
- Feature scaling
- Train/Test split
- KNN Classification
- Accuracy evaluation
- Confusion Matrix visualization
- K-value selection plot

## Technologies Used

- Python 3
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
