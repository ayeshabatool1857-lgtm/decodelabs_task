# AI Project 3 – Skill Recommendation System

## Overview

This project implements a simple recommendation engine that suggests suitable job roles based on user skills.

The system compares user-entered skills with a dataset and recommends the closest matching careers.

## Features

- Load skills dataset from CSV
- User skill input
- Similarity calculation
- Rank recommendations
- Display top matching job roles

## Technologies Used

- Python 3
- CSV module
- Math module
- Collections
