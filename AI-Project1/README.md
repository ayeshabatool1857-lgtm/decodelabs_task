# AI Project 1 – Rule-Based Chatbot

## Overview
This project implements a simple rule-based chatbot using Python. The chatbot responds to predefined user inputs using a knowledge base stored as a dictionary.

## Features

- Rule-based conversation
- Predefined responses
- Continuous chat loop
- Case-insensitive input handling
- Exit command using "bye"

## Technologies Used

- Python 3

## Project Structure

```
AI-Project1/
│── rule_based_chatbot.py
│── README.md
```

## How to Run

```bash
python rule_based_chatbot.py
```

## Example

```
You: Hi
Bot: Hey! How's it going?

You: What is your name?
Bot: My name is Bot.

You: Bye
Bot: Goodbye!
```
